# 霓虹游戏厅 · 祝福显化扭蛋机

一个纯静态、无框架的创意互动网页。玩家走进一间温暖复古的霓虹游戏厅，看见一台主舞台扭蛋机：投入心愿币、转动旋钮后，玻璃仓中的彩色胶囊滚动并点亮，一颗胶囊从出口滚落到托盘，自动打开并弹出一张祝福卡片。

> 这里的“显化”是创意互动与情绪价值的表达，不构成对现实结果的承诺。

## 本地打开

仓库内的最终可部署文件在 `dist/` 目录中：

```bash
manifest-gacha-arcade/dist/index.html
```

项目不需要构建工具或本地服务，直接双击 `dist/index.html`，或在浏览器中打开该文件即可。如果偏好本地静态服务，也可以在项目根目录运行：

```bash
cd manifest-gacha-arcade/dist
python3 -m http.server 4173
```

然后访问 `http://localhost:4173/`。该地址仅用于本地预览，不是公网发布链接。

## 交互流程

1. 点击左下角的“心愿币”完成投币。
2. 投币后，旋钮解锁并出现“转”字提示。
3. 点击旋钮，玻璃仓内胶囊开始旋转。
4. 一颗胶囊被随机选中并发光。
5. 胶囊沿出口路径滚落，落在机器下方的托盘里。
6. 胶囊自动打开，不需要用户再次点击。
7. 祝福卡片弹出，包含祝福名称、温暖解释、今天的小行动和留存短句。
8. 可点击“复制祝福”，或点击“再抽一次”进入下一轮。

## 场景与设计

- 完整游戏厅空间：透视地砖、反光地面、光斑、漂浮光尘、机器投影。
- 中景是主角显化扭蛋机，前景有地面光点与散落心愿币氛围。
- 背景包含可辨认的夹娃娃机、双人街机、奖品兑换机和复古街机，并带有远近虚化。
- 视觉以奶油黄、樱桃红、薄荷绿、暖橙和半透明塑料质感为主，避免纯暗紫赛博风。
- 桌面端和手机端均有自适应布局；同时尊重系统的“减少动态效果”设置。
- 祝福结果随机出现，并使用轻量去重策略，降低连续重复抽中同一结果的概率。

## 部署

`dist/` 是最终静态产物，可直接部署到任意静态托管平台、CDN 或对象存储静态站点。常见方式：

### GitHub Pages

1. 在仓库设置中启用 Pages。
2. 选择部署分支，并将站点根目录指向 `manifest-gacha-arcade/dist`。
3. 访问 GitHub Pages 生成的公网地址。

### Vercel / Netlify / Cloudflare Pages

1. 将仓库导入对应平台。
2. 构建命令留空。
3. 将输出目录设置为：

```text
manifest-gacha-arcade/dist
```

也可以直接把 `dist/` 目录拖拽到平台的静态上传入口。
